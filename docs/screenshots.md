# Screenshots: planned for a later update

[← README](../README.md)

Screenshots were deliberately deferred for this release. No image in this repository claims to be photographic or screenshot evidence of the experiment. The current result is documented in the [verification record](testing.md).

When available, useful evidence would include:

1. The original 60 Hz Advanced display page, if an authentic capture exists.
2. The final page showing desktop mode, active signal mode, and the selected 120 Hz rate together.
3. The relevant macOS display setting.
4. A cropped view of only the five configuration entries, if helpful.

Do not recreate a missing before screenshot and present it as original evidence. Redact account names, email addresses, private paths, VM identifiers, and unrelated screen content. Keep the resolution and rate readable. Include the capture date and explain whether each image comes from the original session or a later reproduction.

Future files can be stored under `docs/images/` and linked from the README with descriptive alt text. No broken image placeholders are included now.
